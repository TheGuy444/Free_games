# Free Games

AI created free games. Each game lives in its own folder.

| Game | Folder | How to play |
|------|--------|-------------|
| The Ronin's Road | [`Ronins_Road/`](Ronins_Road/) | Open `Ronins_Road/index.html` in a browser |
| Hollywood Tycoon | [`Hollywood_game/`](Hollywood_game/) | `cd Hollywood_game && python3 run.py`, then visit http://localhost:8000 (Python 3.10+, no installs) |
| Cage Dynasty (MMA promotion sim) | [`Cage_Dynasty/`](Cage_Dynasty/) | `cd Cage_Dynasty && npm install && npm run web`, then visit http://localhost:5173 (Node 20+) |
